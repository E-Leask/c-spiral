🌀 The Clockwise/Spiral Rule

Any C declaration can be decoded into plain English in 3 steps:

1
Find the Identifier

Start at the variable name (e.g. str or fp).

2
Move Clockwise / Spiral

Read tokens moving right, turning left when hitting parens (), brackets [], or semicolon ;:

  • [N] → "array N of..."
  • (type1, type2) → "function passing type1, type2 returning..."
  • * → "pointer to..."
3
Parentheses First

Always resolve elements inside parentheses before stepping outside!

Example: char *str[10];
  1. Start at str → "str is..."
  2. Move right to [10] → "an array 10 of..."
  3. Turn left to * → "pointers to..."
  4. Reach char → "char"
